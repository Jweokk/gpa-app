# GPA · 语音成绩登记

一个基于浏览器的语音成绩录入工具，支持通过麦克风语音输入学生成绩，无需安装任何软件。

## 功能特性

- **上传 Excel**：导入 .xlsx / .xls 格式的学生名单，自动识别姓名列和已有成绩
- **批量语音录入**：一次性朗读「姓名+成绩」，自动匹配学生并填入
- **顺序语音录入**：按学生名单顺序依次朗读分数，自动填入
- **核对模式**：朗读已录入的成绩进行核对，可调节播报间隔
- **智能姓名匹配**：支持拼音匹配、模糊匹配，自动识别中英文数字
- **导出 Excel**：一键下载带成绩的 Excel 文件

## 使用方法

### 上传文件
1. 点击上传区域或拖拽 Excel 文件到页面
2. 文件格式要求：第一列为学生姓名（第一行为表头），可含成绩列
3. 示例：
   ```
   姓名 │ 成绩
   张三 │ 85
   李四 │ 92
   ```

### 批量模式（默认）
1. 点击麦克风按钮开始录音
2. 一次性朗读格式：`张三 85，李四 92`
3. 系统自动匹配姓名并填入对应成绩
4. 匹配不准确时可手动选择候选人

### 顺序模式
1. 点击「顺序」标签切换
2. 按学生名单顺序朗读分数
3. 每个数字后稍作停顿
4. 自动填入当前及后续未录入的学生

### 核对模式
1. 点击「核对」标签切换
2. 点击「朗读」按钮，系统按顺序播报已录入成绩
3. 调节间隔滑块控制播报速度
4. 可与原始成绩单逐一比对

## 技术栈

- **Web Speech API**：浏览器原生语音识别，支持中文普通话
- **pinyin-pro**：拼音匹配库，提升姓名识别准确率
- **xlsx (SheetJS)**：Excel 文件解析与导出
- 纯前端，无后端依赖
