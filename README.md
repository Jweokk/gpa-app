# GPA · 语音成绩登记

一个基于浏览器的语音成绩录入工具，支持通过麦克风语音输入学生成绩，无需安装任何软件。

在线使用：https://gpa.bobanderson.blog

## 功能特性

- **上传 Excel**：导入 .xlsx / .xls 格式的学生名单，自动识别姓名列
- **批量语音录入**：一次性朗读「姓名+成绩」，自动匹配学生并填入
- **顺序语音录入**：按学生名单顺序朗读分数，支持文字粘贴/语音
- **引导模式**：分两步依次说姓名→说成绩，可覆盖已有记录
- **核对模式**：朗读已录入的成绩进行核对，可调节播报间隔
- **智能姓名匹配**：支持拼音匹配、模糊匹配，自动识别中英文数字
- **清除成绩**：勾选学生后一键清除，方便重新录入
- **导出 Excel**：一键下载带成绩的 Excel 文件

## 使用方法

### 上传文件

1. 点击上传区域或拖拽 Excel 文件到页面
2. 文件格式要求：第一列为学生姓名（第一行为表头）
3. 示例：
   ```
   姓名
   张三
   李四
   ```

### 📝 批量模式（默认）

1. 点击麦克风按钮开始录音（需允许麦克风权限）
2. 一次性朗读格式：`张三 85，李四 92`
3. 系统自动匹配姓名并填入对应成绩
4. 匹配不准确时可手动选择候选人

### 📋 顺序模式

1. 点击「顺序」标签切换，自动开始录音
2. 按学生名单顺序朗读分数，每个数字后稍作停顿
3. 也可在输入框中粘贴数字（如通过 iPhone 快捷指令听写）
4. 点击左侧名单可切换起始学生

### 🎯 引导模式

1. 点击「引导」标签，点「开始」按钮
2. 步骤 1：说学生姓名 → 系统自动匹配或列出候选
3. 步骤 2：说成绩 → 倒计时自动确认（可调 1-6 秒）
4. 确认后语音播报"张三 85分"，自动进入下一学生
5. 可直接说名字覆盖已有成绩

### 🔊 核对模式

1. 点击「核对」标签切换
2. 点击「朗读」按钮，系统按顺序播报已录入成绩
3. 调节间隔滑块控制播报速度
4. 可用前一个/后一个按钮跳转检查

## 技术栈

- **Web Speech API**：浏览器原生语音识别，支持中文普通话
- **SpeechSynthesis**：浏览器语音合成，用于核对播报
- **pinyin-pro**：拼音匹配库，提升姓名识别准确率
- **xlsx (SheetJS)**：Excel 文件解析与导出
- 纯前端，无后端依赖
